## Verdict

Nothing blocks. The security model holds in the code: every write and every private read goes through a database function that takes the caller from the token, the admin needs a second factor, nothing a player wrote is ever inserted as HTML, and the content security policy allows no inline script. The worst thing a stranger sees is the home page's four empty screenshot frames: an honest placeholder, but it reads as unfinished.

## Polish (4)

- **[NAV-3] Fixed during the audit:** `/download`'s hidden APK button carried `href="#"` before a release; it now has no address until the script sets the real one.
- **[DES] Withdraw and the admin's deletes use the browser's own confirm box** — `scripts/community.ts` (withdraw), `scripts/admin-ui.ts` (delete a question, an update, the moderation actions). Each names the thing and says what happens, which is the rule that matters; the kit's own confirmation comes with Phase 11.
- **[SEC-8] The page data blocks don't escape `<`** — `set:html={JSON.stringify(…)}` in `Base.astro`, `Home.astro`, `Community.astro`, `Download.astro`. All of it is the site's own build-time data (the reel's club names, the page's words), so nothing a player wrote can reach it; a `<\/script>` in a future data change would still break the page. Fix if the data ever comes from players: replace `<` with `<` in one helper.
- **[SEC-15] `latest.json` is served with `Access-Control-Allow-Origin: *`** — the game's `vercel.json`. A public file with no credentials, read by the site's download page; an allow-list of one address would do the same. Accepted.
